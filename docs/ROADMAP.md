# 路线图

## M0：当前 MVP
- [x] REST API、结构化需求规格、确定性状态机
- [x] 四类本地演示 Agent、SQLite 和产物追踪
- [x] 基础测试、CI、PRD/架构/API/安全文档

## M1：真实模型与可恢复工作流
- [ ] LLM provider 接口、超时/重试和 JSON Schema 输出校验
- [ ] Temporal 或 LangGraph 持久化执行
- [ ] PostgreSQL 迁移、并发控制、需求澄清与人工确认

## M2：仓库只读分析
- [ ] GitHub App 最小权限接入
- [ ] 目录树、依赖、测试入口和关键符号分析
- [ ] 提示注入隔离和项目事实索引

## M3：受控编码与验证
- [ ] 隔离工作副本/分支、沙箱和工具权限策略
- [ ] 自动测试、lint、类型检查、安全扫描
- [ ] 审查与失败返工循环，审批后创建 PR

## M4：交互验收与交付
- [ ] staging 与 Playwright 验收
- [ ] 交付清单、回滚方案和发布审批
- [ ] 线上指标与回滚触发条件

## M5：知识飞轮与评测
- [ ] 项目事实、经验、当前任务分层
- [ ] 固定回归评测集与模型版本比较
- [ ] 成本、延迟、首次通过率、人工介入率和变更失败率看板
